# Timur Translator Realtime v16.4.0

UI polish update:
- Refreshed the setup screen and live translation window with softer typography and cleaner button styling.
- Switched to platform-friendly fonts: `Segoe UI` on Windows and `Avenir Next` on macOS.
- Improved the top bar in the translation window with a clearer title, subtitle, and status chip.
- Renamed several labels and buttons to a cleaner title-case style.
- Increased button padding and improved hover / border styling for a more polished app feel.
- Kept all previous stability fixes, including macOS SSL certificate handling and theme contrast fixes.

Functional highlights retained:
- OpenAI Realtime translation.
- Microphone mode and system-audio mode.
- Windows WASAPI loopback capture.
- macOS BlackHole 2ch system-audio capture.
- Automatic headset microphone prioritization.
- Theme customization, opacity, scaling, and overlay mode.
- Turkish language support.
